# Architecture Decision Records

This directory records decisions that affect multiple Wicofe components or establish long-lived project constraints.

## Format

Create records as `NNNN-short-title.md` with:
- **Status:** Proposed, Accepted, Superseded, or Rejected.
- **Context:** problem and constraints.
- **Decision:** selected approach.
- **Consequences:** benefits, costs, risks, and follow-up work.
- **Alternatives:** considered options and reasons for rejection.

Do not silently rewrite an accepted decision. Supersede it with a new ADR and link both records.
